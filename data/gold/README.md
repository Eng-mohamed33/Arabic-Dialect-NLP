# Gold test set (Egyptian -> MSA)

اكتب هنا 200-300 جملة مصرية مع ترجمتها للفصحى بإيدك، وسمّي الملف `egy_msa_gold.csv`
بنفس أعمدة `egy_msa_gold_template.csv`:

| العمود | المعنى |
|---|---|
| id | رقم الجملة |
| egyptian | الجملة المصرية |
| msa | الترجمة الفصحى المرجعية |
| genre | يومي / سوشيال / رسمي / ... |
| notes | أي ملاحظة |

- نوّع الأنواع (genres) والأطوال، ومتنسخش جمل من داتا التدريب.
- `python -m src.data.prepare` بيقرأ الملف ده تلقائياً ويشيل من train/valid أي جملة بتتكرر فيه.
- ده تقييمك الأساسي للمُحوِّل: متستخدمهوش في التدريب أو ضبط الـ hyperparameters.
